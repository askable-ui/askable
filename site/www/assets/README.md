# Website Assets

- `inter-latin-variable.woff2`: Inter Latin variable font, distributed by `@fontsource-variable/inter` 5.3.0. Unmodified, licensed under SIL Open Font License 1.1. See `INTER-LICENSE.txt`.
- Icons in `index.html`: a subset of Lucide 1.48.0, generated from `lucide-static` icon nodes and inlined for consistent Safari color inheritance. Licensed under ISC with upstream MIT notices. See `LUCIDE-LICENSE.txt`.

These are local website dependencies, not promotional assets. Keeping them local avoids third-party font and icon requests on page load.
