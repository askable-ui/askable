Structured data, attached to the element it describes.

          
<div
  data-askable='{
    "metric": "Monthly revenue",
    "value": 128400,
    "change": "+12.4%"
  }'
>
  $128,400
</div>

        

        

          
User intent becomes prompt-ready context.

          
import {
  createAskableContext
} from '@askable-ui/core';

const askable = createAskableContext();

askable.observe(document, {
  events: ['click']
});

        

        

          
The question, selection, and app-owned sources in one request.

          
const request = await askable.toAgentRequest(
  question,
  {
    packet: selectedPacket,
    contextFromPacket: true,
    selectionFromPacket: true,
    sources: ['accounts']
  }
);

At home in your stack.

      
One core, with adapters for the way you build.

      

        
          
JS · Core

          
@askable-ui/core

          
Framework-agnostic observer and context builder. Zero dependencies.

          
        
        
          
JS · React

          
@askable-ui/react

          
Components and hooks for selection, app data, and chat. React 17+.

          
        
        
          
JS · Vue

          
@askable-ui/vue

          
Reactive context and app-owned sources for Vue 3.

          
        
        
          
JS · Svelte

          
@askable-ui/svelte

          
Svelte 4 stores and Svelte 5 runes for reactive UI context.

          
        
        
          
JS · SolidJS

          
@askable-ui/solid

          
Fine-grained reactive context and source primitives for SolidJS.

          
        
        
          
TS · Angular

          
@askable-ui/angular

          
Injectable services and directives for Angular 16+.

          
        
        
          
TS · Qwik

          
@askable-ui/qwik

          
useAskable() and <Askable> for Qwik City apps: resumable, zero-JS-by-default.

          
        
        
          
HTML · Any framework

          
@askable-ui/web-component

          
<askable-context> custom element: zero build step, works in HTMX, Ember, or plain HTML via CDN.

          
        
        
          
Transport

          
@askable-ui/bridge

          
Deliver context to a chat UI, extension, iframe, or HTTP endpoint.
